# petfeeder
This is where we put all our codes to build app for out project of creating a smart pet feeder.

The Smart IoT Pet Feeder is an innovative solution designed to address challenges in maintaining 
consistent feeding schedules and portion sizes for pets. This system combines IoT technology, mobile app development, 
and sensor integration to ensure that pets are fed at the right time and in the correct amount, promoting their health 
and well-being. Through an intuitive mobile application, pet owners can schedule feeding times, specify food portions, 
and receive real-time updates about the feeder's status. The system also notifies users when the food dispenser is low, 
when the food bowl requires cleaning, or if there are any operational issues.
